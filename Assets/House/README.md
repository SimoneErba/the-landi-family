# Starting House Modules

These are the first reusable visual modules for the House screen. They depict the Landi starting home in the early 1900s:

| Asset | Starting role | Later gameplay use |
| --- | --- | --- |
| `bedroom-01.png` | One shared bedroom | Split into bedrooms, furnish, renovate, age with the family |
| `kitchen-01.png` | One kitchen and family table | Expand, modernise, host meals and family conflicts |
| `outdoor-washroom-01.png` | Outdoor washroom and privy | Build an indoor bathroom, improve sanitation, retain as an outbuilding |

All assets use transparent backgrounds and depict an empty room or structure. They are intended as the visual layer over a future grid or room model, so the simulation owns capacity, condition, ownership, costs, and accessibility.

The three assets establish the initial house state: **one bedroom, one kitchen, and an outdoor bathroom**.

## Generation brief

Generated with the built-in image generator as warm painterly European domestic realism: early-1900s Italian interiors, faded plaster, walnut, terracotta tile, muted olive details, no people, no text, and transparent backgrounds.
